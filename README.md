# R Burgues — Cardápio Digital

Site gourmet responsivo da R Burgues, em Jatiúca, Maceió/AL.

## Estrutura
- `index.html`: landing page e estrutura do cardápio
- `css/style.css`: estilos e responsividade
- `js/config.js`: WhatsApp
- `js/app.js`: interações, carrinho e checkout
- `data/cardapio.js`: 11 produtos, preços e descrições
- `assets/images/`: logotipo e fotografias

## Como usar
Abra `index.html` no navegador. Os botões de WhatsApp enviam um pedido detalhado para **(82) 99115-9607**; o pedido e a entrega são confirmados pela equipe. O carrinho não processa pagamentos.

## Publicação
Site estático pronto para Cloudflare Pages (raiz do repositório; sem build). 

**Antes de divulgar:** confirme valores, ingredientes com descrição incompleta, disponibilidade e condições de entrega. As fotografias são recortes de imagens disponibilizadas e podem ser substituídas por arquivos originais.
